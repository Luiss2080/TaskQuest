❓ Ayuda y Tutorial

¡Bienvenido a TaskQuest!

Convierte tus tareas diarias en misiones épicas. Gana XP, sube de nivel y mantén tu racha.

Cómo Empezar

1️⃣

Crea tu primera misión

Escribe qué tarea quieres completar, elige su dificultad y categoría.

2️⃣

Completa tareas y gana XP

Marca las tareas como completadas para ganar experiencia según su dificultad.

3️⃣

Sube de nivel

Acumula XP para subir de nivel. Cada nivel requiere más experiencia.

4️⃣

Mantén tu racha

Completa al menos una tarea cada día para mantener tu racha activa.

Niveles de Dificultad

⭐ Fácil +10 XP

Tareas rápidas o simples (5-15 minutos)

⭐⭐ Media +25 XP

Tareas de complejidad moderada (30-60 minutos)

⭐⭐⭐ Difícil +50 XP

Tareas complejas o largas (1-3 horas)

⭐⭐⭐⭐ Épica +100 XP

Proyectos importantes o de gran esfuerzo (3+ horas)

Quest Diaria

Completa 3 tareas en un día para obtener un bonus de +50 XP.

La quest se reinicia cada día a medianoche. ¡Aprovecha este bonus diario para subir de nivel más rápido!

Sistema de Rachas

Tu racha aumenta cada día que completes al menos una tarea.

💡 Consejo:

Mantén una racha larga para demostrar tu constancia. Si pasas un día sin completar tareas, tu racha se reinicia a 0.

Consejos Pro

  • Divide tareas grandes en varias más pequeñas para ganar XP más frecuentemente
  • Completa tareas fáciles al inicio del día para asegurar tu racha
  • Usa categorías para organizar mejor tus tareas
  • Reserva tareas épicas para proyectos realmente importantes
  • Exporta tus datos regularmente desde Configuración como backup
